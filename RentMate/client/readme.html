📘 RentMate - README

🏪 Store Name:

RentMate

📦 What are you selling?

This is a rental platform where users can post and rent items such as electronics, tools, or equipment.

📄 Additional Pages:

  • RentMate AI: Allows querying any product found on the internet to determine the optimal rental price for it. (Server: POST /api/ai/price-suggest)
  • Stats: Displays basic statistics about the user's activity (number of products created, purchases made, average rental days, and more). (Server: GET /api/stats/my)
  • Dispute Center: Allows users and the Admin (both sellers and buyers) to manage discussions about complaints regarding delays or damaged products (open disputes, replies, and closing disputes). (Server: GET /api/disputes, POST /api/disputes, POST /api/disputes/:id/reply, POST /api/disputes/:id/resolve)
  • Change User Info: Page for editing user details and display preferences (including password changes). (Server: GET /api/account/profile, POST /api/account/profile, POST /api/account/change-password)

🛠️ How to Operate:

  • RentMate AI ChatBox: Go to the home page, enter a product name, your price idea, rental days and his description, and the system will search the web to suggest an optimal rental price.
  • Stats: Open the home page, click on "Stats" button and your statistics will load automatically — no manual input needed (Works only if you are logged in).
  • Dispute Center: View the list of disputes related to you, open a new dispute, reply in an existing thread, or resolve a dispute if you are the owner/admin (Works only if you are logged in).
  • Change User Info: Log in, click on "Change User Info" button, edit your full name and preferred theme, then click Save. To change your password, fill in your old and new passwords and click Change. The button is visible only if you are logged in and you cant change the full name of the admin.

🧭 Key API Routes (selected):

  • GET /api/products — Retrieve all products (public)
  • POST /api/products — Create a new product (auth required)
  • DELETE /api/products/:id — Delete a product (auth required, dynamic, owner/admin only)
  • GET /api/cart — Get cart items (auth required)
  • POST /api/cart/add — Add item to cart (auth required)
  • POST /api/cart/remove — Remove item from cart (auth required)
  • POST /api/cart/clear — Clear all cart items (auth required)
  • POST /api/cart/update-duration — Update rental days for an item (auth required)
  • POST /api/checkout/pay — Complete purchase and clear cart (auth required)
  • GET /api/purchases — Get all purchases for the logged-in user (auth required)
  • GET /api/users/status — Get login status (public)
  • POST /api/users/status — Toggle user mode (auth required)
  • POST /api/users/login — Log in a user (public)
  • POST /api/users/register — Register a new user (public)
  • POST /api/users/logout — Log out current user (auth required)
  • GET /api/users/activity — Get activity log for the logged-in user (auth required)
  • GET /api/admin/activity — Get admin activity log (admin only)
  • POST /api/ai/price-suggest — AI price suggestion based on external web search (auth required)
  • GET /api/stats/my — Get basic user stats (auth required)
  • GET /api/disputes — List disputes related to the logged-in user (auth required)
  • POST /api/disputes — Open a new dispute (auth required)
  • POST /api/disputes/:id/reply — Reply in a dispute thread (auth required)
  • POST /api/disputes/:id/resolve — Resolve a dispute (auth required, owner/admin only)
  • GET /api/account/profile — Get profile details (auth required)
  • POST /api/account/profile — Update profile details (auth required)
  • POST /api/account/change-password — Change account password (auth required)
  • GET /readme.html — Serve README page (public)
  • GET /llm.html — Serve LLM report page (public)
  • GET * — Fallback route serving index.html

⚠️ What was hard to do?

Ensuring consistent session handling, syncing cart state across UI and backend, and controlling rental days per item were challenging. Also, preventing DoS attacks by validating payloads and using rate limits was important. Integrating external AI search and model output (strict JSON) required careful prompt design and error handling.

🧪 How did you test the app?

Automated testing with test.js using node-fetch. The script prints which tests run and whether they passed, including dynamic routes, cookie rotation, and all new endpoints. Manual testing was also performed through the browser.

Run the following commands in the RentMate directory to install node-fetch v2 as a dev dependency and execute the test script:
>> npm i -D node-fetch@2
>> node client/scripts/test.js
