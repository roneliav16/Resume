LLM Assistance Overview

During development I used an LLM (e.g., ChatGPT) in a supportive way. It helped accelerate ideation, polish, and validation of approaches. Core design and implementation decisions remained mine.

How the LLM Was Used

  • RentMate AI: Prompt crafting for robust JSON-only output, integrating an external web search provider with a generative model, and handling edge cases/fallbacks when API keys are missing.
  • Stats: Choosing a lightweight charting approach (Chart.js) and shaping a compact API response structure for client rendering.
  • Dispute Center: Structuring a simple dispute schema (open/reply/resolve), basic validation for inputs, and secure UI rendering of messages.
  • Testing (test.js): Designing an end-to-end flow that prints each test step, maintains cookies across requests (including session rotation), and covers all dynamic routes.

What Was Not Delegated

  • Core server logic, route structure, and data flow between modules.
  • Session handling, cookies, and per-user cart/purchases persistence.
  • Product/cart/checkout features and their validations.
  • Security hardening and error handling across modules.

Notes

The LLM provided guidance, reviews, and suggestions. I integrated these selectively, adapting them to my project's constraints and data structures.
